Closest Pair of Points

Compare Brute-Force and Divide-and-Conquer on randomly generated points.

Input

Ready. Choose N and run the comparison.

Algorithms

Brute-Force: checks every pair. O(N²).

Divide-and-Conquer: recursively splits points and checks the middle strip. O(N log N).

Correctness and corner cases

algorithms

Brute-Force examines every unordered pair. Divide-and-Conquer considers the closest pair in the left half, the right half, or across the dividing line; the strip check handles cross-boundary pairs. Both are run on the same point set and their distances are compared.

Corner cases
  • N < 2: no pair exists.
  • N = 2: only one pair exists.
  • Duplicate points: minimum distance is zero.
  • Collinear points and equal x/y coordinates are supported.
  • Different pairs may be returned when multiple pairs tie for the same minimum distance.
Complexity comparison

Brute-Force: O(N²) time and O(1) auxiliary space. Divide-and-Conquer: O(N log N) time and O(N) auxiliary space. For small N, sorting overhead may affect measured performance.
