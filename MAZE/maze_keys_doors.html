Algorithm & correctness

State: (row, column, key mask). Each bit records whether one of the six keys has been collected. The same cell with different keys is a different search state.

  • Why BFS? Every move costs exactly one step, so BFS explores states in nondecreasing distance.
  • Door rule: A door is entered only when its matching key bit is set.
  • Optimality: The first exit state reached by BFS has minimum distance among all legal routes. If no exit state is reached, the answer is -1.
  • Complexity: At most N² × 2ᵀ states and four moves per state: O(N² 2ᵀ) time and space.

Corner cases handled: no path, walls, multiple routes, collecting a key before its door, revisiting cells with a different inventory, and invalid CSV dimensions. Start and exit must each appear exactly once.
